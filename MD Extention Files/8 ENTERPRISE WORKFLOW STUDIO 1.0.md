# **7. WORKFLOW BUILDING BLOCKS**

Every workflow consists of:

## **Trigger**

Starts workflow.

Examples:

- Product Created

- DAD Submitted

- Revenue Drops

## **Condition**

Decision criteria.

Examples:

If Revenue < Target

If DAD Status = Pending

## **Action**

System activity.

Examples:

- Create Task

- Send Notification

- Update Status

## **Approval**

Human decision.

Examples:

- CTO Approval

- Governance Approval

## **AI Decision**

Agent recommendation.

Examples:

- Risk Analysis

- Revenue Recommendation
