# **DAIOS ENTERPRISE RACI MATRIX 1.0**

## **Responsibility, Accountability, Consultation & Information Governance Framework**

# **1. PURPOSE**

The DAIOS Enterprise RACI Matrix defines:

### **Who Owns What**

### **Who Approves What**

### **Who Executes What**

### **Who Must Be Consulted**

### **Who Must Be Informed**

for every:

- Module

- Workflow

- Service

- Product

- AI Agent

- Revenue Activity

- Governance Activity

inside DAIOS.

# **2. RACI DEFINITIONS**

## **R = Responsible**

The person or office that performs the work.

Example:

Developer builds API.

## **A = Accountable**

The final owner of the outcome.

Only one accountable owner should exist.

Example:

CTO accountable for architecture.

## **C = Consulted**

Provides input before decision.

Example:

Security Office consulted before release.

## **I = Informed**

Must be informed after decision.

Example:

Chairman informed about major release.

Every module.
Every workflow.
Every service.
Every decision.

Must be governed through this matrix.

This document becomes mandatory for all DAIOS operations.
